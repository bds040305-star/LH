LH 청약+ 전체완성본 v3

실행 방법
1. VS Code에서 이 폴더 전체를 엽니다.
2. index.html에서 Live Server로 실행합니다.
3. header.html / footer.html을 fetch로 불러오므로 반드시 Live Server를 사용하세요.

이미지 넣는 방법
현재 로고 / 아이콘 / 지도 / 푸터 이미지 자리는 전부 비워두었습니다.

예:
현재
<span class="media-slot icon-slot"></span>

이미지 적용
<img src="./images/header-icon/search.svg" alt="검색" class="media-slot icon-slot">
