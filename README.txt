LH 청약플러스 — 기존 디자인 통일 + 가족 서명 시연

VS Code에서 폴더를 열고 index.html을 Live Server로 실행하세요.
확인 경로: 공고 상세 → 서류 준비하기 → 서명 요청 보내기 → 카카오톡/문자 선택 → 가족 서명 요청 → 동의 → 직접 서명 → 서류 준비 화면으로 돌아가기.

디자인 기준: 기존 LH 공통 CSS의 66px 페이지 헤더, 23px 헤더 제목, #0066B3 버튼/포인트, 80px 하단 메뉴를 그대로 재사용했습니다.
변경: document-checklist.html, signature-request.html, css/mockup-screen.css, js/mockup-screen.js.
기존 다른 페이지는 그대로 두었습니다. 아이폰 프레임과 포트폴리오 배경은 포함하지 않았습니다.
이것은 한 브라우저 내 시연입니다. 실제 메시지 발송, 개인정보 수집, 전자서명 인증, LH 서류 제출을 하지 않습니다.
기존 ZIP처럼 공통 CSS/JS/이미지는 GitHub Pages 배포본의 외부 URL을 일부 사용하므로 인터넷 연결이 필요합니다.
